Темы: приветствия • имя и национальность • «Где твой дом?» Группа: 4 ученика + ведущий.

Впишите имена. Кнопка «Активный» — чей сейчас ход: ему начисляются баллы. Очки: ✔ = +2, ✖ = 0.

Правила игры

  • Все отвечают вслух по-китайски — письменно только там, где написано.
  • Правильный устный ответ = +2 активному игроку. Подсказка ведущего = +1.
  • Нельзя повторять одного активного игрока два раза подряд.
Блок 1 • 15'

👋 Урок 1: Приветствия

你好！ Nǐ hǎo! — Привет! 你好吗？ Nǐ hǎo ma? — Как дела? 我很好。 Wǒ hěn hǎo. — У меня всё хорошо.

Слова: 你 nǐ — ты, 好 hǎo — хороший, 我 wǒ — я, 很 hěn — очень, 吗 ma — вопросительная частица.

1. Флеш-карточки (по очереди переворачивайте и читайте вслух)

2. Игра «Найди пару» — кто быстрее?

Ведущий выбирает активного игрока. Найдите пару «иероглиф — перевод». За каждую пару +2. Затем смена игрока.

3. Мини-диалоги в парах (3 минуты)

АБ
你好！你好！
你好吗？我很好。
你好吗？我很好。

Пары: игрок 1+2, игрок 3+4. Потом меняются. Каждая пара показывает диалог классу = +2 каждому.

Блок 2 • 20'

🙋 Урок 2: Имя и национальность

你叫什么？ — Как тебя зовут? 我叫李小龙。 — Меня зовут Ли Сяолун.
你是哪国人？ — Ты из какой страны? 我是中国人。 — Я китаец.

叫 jiào — звать, 什么 shénme — что, 是 shì — быть, 哪 nǎ — какой, 国 guó — страна, 人 rén — человек, 中国 Zhōngguó — Китай, 英国 Yīngguó — Англия, 美国 Měiguó — Америка.

1. Собери предложение (нажимайте слова по порядку)

2. Раунд «Переводчик» — по кругу

Ведущий показывает фразу на русском → активный игрок говорит по-китайски. ✔ +2. Круг: 1→2→3→4.

Нажмите «Следующая фраза»

3. Викторина «Страны» (устно)

Ведущий спрашивает, игроки поднимают руку: 中国人 — китаец, 英国人 — англичанин, 美国人 — американец. 我是…人!

  • «Ты американец?» → 我是美国人。
  • «Ты англичанин?» → 我是英国人。
  • «Ты китаец?» → 我是中国人。
Блок 3 • 20'

🏙 Урок 3: Где твой дом?

你家在哪儿？ Nǐ jiā zài nǎr? — Где твой дом?
我家在北京。 Wǒ jiā zài Běijīng. — Мой дом в Пекине.

家 jiā — дом, 在 zài — находиться в, 哪儿 nǎr — где, 北京 Běijīng, 上海 Shànghǎi, 香港 Xiānggǎng, 他 tā — он.

1. Флеш-карточки

2. Игра «Карта Китая» — найди пару «город — место»

Ведущий называет город по-русски, активный игрок кликает иероглиф, потом ищет его перевод. +2 за пару.

3. Цепочка диалогов «Где твой дом?» (по кругу, 4 игрока)

№РольРеплика
1Спрашивает 2-го你家在哪儿？
2Отвечает, спрашивает 3-го我家在北京。你家在哪儿？
3Отвечает, спрашивает 4-го我家在上海。你家在哪儿？
4Отвечает, спрашивает 1-го我家在香港。你家在哪儿？
1Замыкает цепочку我家在北京。

Прогнать цепочку 2 раза, меняя города. Каждый правильный круг = +2 всем.

4. Блиц «Он/она»

Ведущий: «Он из Пекина» → игрок: 他家在北京。 «Она из Шанхая» → 她家在上海。 Смена 他/她 — внимательно!

Игры • 20'

🎮 Игры на 4 человек

Игра 1: «Быстрый пингвин» (5–7 мин)

Появляется слово на русском — кто первым назовёт его по-китайски, тот получает балл (ведущий жмет ✔). Можно играть «на вылет»: ошибся — пропуск хода.

Нажмите «Следующее слово»

Игра 2: «Кто я?» (7–10 мин)

Устройство: один игрок отворачивается, остальные решают, кто он (например «американец», «Пекин»). Игрок задаёт вопросы классу по-китайски: 我是中国人吗？Класс отвечает: 是 / 不是. Угадал = +3.

Карточки личностей (ведущий выбирает шёпотом): 中国人, 英国人, 美国人, 北京人, 上海人, 香港人, 老师 (учитель), 学生 (студент)
—

Игра 3: «Разорви предложение» (5 мин)

Ведущий читает предложение с паузами, игроки повторяют хором всё длиннее: 我 → 我家 → 我家在 → 我家在北京。Кто сбился — выбывает до следующего предложения. Победитель раунда +3.

—
